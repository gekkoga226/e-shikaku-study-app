# 最初に読むファイル — 非エンジニア向け

このZIPは、E資格の学習用Webアプリを **Google Apps Script + 既存Googleスプレッドシート + Google Drive** だけで動かすための一式です。

## まず全体像

難しい言葉を使わずに言うと、役割は3つだけです。

1. **Googleスプレッドシート = 学習データの本体**
   - 問題
   - 回答履歴
   - 理解度
   - 弱点
   を保存・計算します。

2. **Google Apps Script = アプリの裏側**
   - 次に出す問題を選ぶ
   - 回答を記録する
   - 画像ZIPをGoogle Driveから読む
   - 回答後に最新理解度を読み直す
   を行います。

3. **HTML = スマホに見える画面**
   - 問題文
   - 選択肢
   - 画像
   - 自信度
   - 正誤・解説
   を表示します。

外部サーバー、外部データベース、有料サービスは使いません。

# この完全版で守っている重要ルール

## 1. 理解度は新方式 v2

アプリ側で「正解したから+20%」とは計算しません。

回答を書き込んだあとに、スプレッドシート
`02_マインドマップ` の `mastery_pct` を読み戻します。

つまり、

**理解度の正解はGoogleスプレッドシート側に1つだけ**

です。

現在の正式ルールは、

`coverage × latest_unique_primary_accuracy`

です。

同じ問題を何度解いてもcoverageは増えません。
再回答した場合は、その問題の最新結果が正答率へ反映されます。

---

## 2. 画像が必要なら、画像が表示できるまで問題を見せない

画像問題では以下の順番になります。

1. 次の問題を内部で選ぶ
2. Google DriveのZIPを読む
3. 必要な画像ファイルを完全一致で探す
4. ブラウザ側でも画像が本当に読み込めるか確認する
5. 全画像が成功した後だけ問題文・選択肢を表示する

途中で1つでも失敗した場合は、その問題を表示せず別問題へ進みます。

**「画像は出なかったけど文章だけで答えてください」にはなりません。**

---

## 3. 回答前に正解をブラウザへ送らない

問題取得時には `correct_option` を返しません。

正解はユーザーが「回答する」を押した後、
サーバー側で採点して初めて返します。
