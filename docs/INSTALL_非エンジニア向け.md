既存アプリを消したり上書きしたりしないので、安全に比較できます。

# 1. ZIPを解凍する

このZIPをPCで解凍してください。

中に次のファイルがあります。

- Code.gs
- ImageManifest.gs
- ImageSupport.gs
- ImageSelfTest.gs
- Index.html
- Styles.html
- Client.html

この7つがアプリ本体です。

`appsscript.json` は参考用なので、最初は触らなくて構いません。

---

# 2. 新しいApps Scriptプロジェクトを作る

Google Apps Scriptの画面で「新しいプロジェクト」を作ります。

ポイントは、

**既存スプレッドシートの「拡張機能 → Apps Script」を上書きするのではなく、新規プロジェクトを作る**

ことです。

プロジェクト名の例:

`E資格_学習Webアプリ_v2`

---

# 3. Code.gsを入れる

新規プロジェクトには、最初から `コード.gs` または `Code.gs` が1個あります。

1. そのファイルを開く
2. 中にあるサンプルコードを全部消す
3. ZIP内の `Code.gs` の中身を全部コピー
4. Apps Script側へ貼り付け
5. 保存

これでアプリの「司令塔」が入ります。

---

# 4. 画像用の3ファイルを追加する

Apps Script左側の「＋」から **スクリプト** を追加します。

次の3つを作ります。

1. `ImageManifest`
2. `ImageSupport`
3. `ImageSelfTest`

Apps Script画面では `.gs` が自動で付く場合があります。
その場合はファイル名だけ入力してください。

それぞれにZIP内の同名ファイルの中身を全部貼り付けます。

---

# 5. 画面用の3ファイルを追加する

今度は「＋」から **HTML** を追加します。

次の3つです。

1. `Index`
2. `Styles`
3. `Client`

それぞれZIP内の

- Index.html
- Styles.html
- Client.html

を丸ごとコピーして貼ります。

---

# 6. 全部保存する

Apps Script上部の保存ボタンを押します。

この時点で、左側にはだいたい以下が並びます。

- Code.gs
- ImageManifest.gs
- ImageSupport.gs
- ImageSelfTest.gs
- Index.html
- Styles.html
- Client.html

ここまでで「部品を置く作業」は終了です。

# 7. まず壊さないテストをする

Apps Script上部の関数選択欄で

`runSelfTest`

を選び、「実行」を押してください。

最初だけGoogleの許可画面が出ます。

このアプリは、

- Googleスプレッドシートを読む・書く
- Google Driveにある修了試験ZIPを読む

必要があるためです。

このテスト自体は `04_学習ログ` に回答を追加しません。

実行結果で `ok: true` になれば基本構造は合格です。

# 8. 画像の設計図テスト

次に

`runImageSupportSelfTest`

- 画像役割マップ

これも学習ログを書きません。

# 9. Google Driveから画像を実際に読めるか確認

これも回答履歴には追加されません。

# 10. テスト用Webアプリを開く

Apps Script右上の「デプロイ」から
**テスト デプロイ**を選びます。

種類は **ウェブアプリ** です。

表示されたテストURLをコピーしてブラウザで開きます。

まずPCで確認してからスマホでも開くのがおすすめです。

---

# 11. 画面で3種類テストする

最低限、次を確認してください。

## A. 文字だけの問題

- 問題文が表示される
- A〜D等を選べる
- 自信度1〜3を選べる
- 回答後に正誤が出る
- 理解度が表示される

## B. 問題文に画像がある問題

重要なのは表示順です。

正常なら、

1. 「画像を取得しています」
2. 画像読み込み確認
3. 問題文と画像が同時に表示

になります。

画像がないまま問題文だけ出た場合はNGです。

## C. 選択肢が画像の問題

- A/B/C/Dの画像が見える
- 画像を含む大きな選択肢ボタンをタップできる
- スマホで横にはみ出さない

---

# 12. 回答がシートへ入ったか確認

実際に1問だけ回答したら、
Googleスプレッドシートの

`04_学習ログ`

を開きます。

新しい回答は、
一番下の物理的な行ではなく、

**上から見て最初の空いている回答行**

へ入ります。

これは現在の正式ルールです。

確認する列:

- question_id
- user_answer
- correct_answer
- is_correct
- confidence
- mastery_before
- mastery_after
- counts_for_mastery

---

# 13. 理解度が新方式になっているか確認

`02_マインドマップ`

の該当論点を見てください。

現在の理解度は M列 `mastery_pct` が正です。

`04_学習ログ` の mastery_before / mastery_after は
その回答時点の「記録写真」のようなものです。

アプリは、

1. 回答ログを書く
2. Sheetの数式を再計算
3. `02_マインドマップ!M` を読む
4. その値を結果画面に表示

という順番で動きます。

そのため旧方式の「正解ごとに+20」は使いません。

---

# 14. 問題なければ本番デプロイ

テストURLで問題なければ、

「デプロイ」→「新しいデプロイ」→「ウェブアプリ」

を選びます。

この学習アプリは自分用なので、
アクセス範囲は **自分だけ、または自分のGoogleアカウントに限定できる最も狭い設定** を選んでください。

匿名で誰でも使える公開設定は不要です。

実行ユーザーは、自分だけが使う前提では
**デプロイした自分** が最も簡単です。

これにより、非公開のDrive ZIPを公開リンクに変更する必要がありません。
