# AI補助解説（Gemini）の設定 — 1回だけの作業

回答したあとの画面に **「AIでさらに噛み砕く」** ボタンが増えました。
このボタンを押したときだけ、AI（Google の Gemini）が登録済みの解説を
やさしい言葉に言い換えてくれます。

> **大事なこと**
> 出題・採点・理解度・学習ログは、これまでどおりスプレッドシートの計算だけで決まります。
> AIは「説明の言い換え」しかしません。○×も理解度も、AIは1ミリも変えません。

このAIを使うには、最初に1回だけ次の3つを行ってください。
2回目からは何もしなくて大丈夫です。

---

## 手順1. Google AI Studio でAPIキーを作る

1. スマホかパソコンで <https://aistudio.google.com/apikey> を開く
2. 学習アプリと同じGoogleアカウントでログインする
3. 「APIキーを作成 (Create API key)」を押す
4. 表示された文字列（`AIza` で始まる長い文字）をコピーする

> この文字列は**パスワードと同じ**です。
> 誰にも見せない、チャットや文書に貼らない、GitHubに置かない。
> この文字列をリポジトリへ書くと、CIの機密情報チェックで自動的に止まります。

---

## 手順2. Apps Script のスクリプトプロパティへ登録する

1. スプレッドシートを開き、**拡張機能 → Apps Script** を開く
2. 左の歯車マーク **「プロジェクトの設定」** を押す
3. 下のほうの **「スクリプト プロパティ」** で「スクリプト プロパティを追加」を押す
4. 次のとおり入力して保存する

   | プロパティ | 値 |
   | --- | --- |
   | `GEMINI_API_KEY` | 手順1でコピーした文字列 |

5. （任意）モデルを変えたいときだけ、もう1行追加する

   | プロパティ | 値 |
   | --- | --- |
   | `GEMINI_MODEL` | 使いたいモデル名 |

   `GEMINI_MODEL` を登録しない場合は `gemini-3.5-flash` が使われます。

APIキーはここにだけ置きます。
アプリのソースコードにも、GitHubにも、ブラウザ側にも保存しません。

---

## 手順3. アプリを開き直して、権限を承認する

AI解説はGoogleの外部サービスへ接続するため、
Apps Script の権限（`script.external_request`）が1つ増えています。

1. デプロイ後にWebアプリのURLを開く
2. 「承認が必要です」と出たら、内容を確認して **許可** を押す
3. これで完了です

増えた権限は「外部サービスへの接続」1つだけです。
スプレッドシートとDrive読み取りの権限は、これまでと同じままです。

---

## 使い方

1. これまでどおり問題に回答する
2. 結果画面に、まず**登録済みの解説**が表示される
3. その下の「AI補助解説」枠にある **「AIでさらに噛み砕く」** を押す
4. 10〜20秒ほどで、AIの説明が表示される

AIは次の順番で説明します。

- 【まず一言】
- 【なぜそうなる？】
- 【他の選択肢との違い】
- 【覚え方】

## よくある質問

**Q. 毎回自動でAIが動いて、料金がかさみませんか？**
A. ボタンを押したときだけ呼び出します。自動では一切呼びません。
さらに、同じ回答に対する解説は1時間保存されるので、
連続で押しても追加の呼び出しは発生しません。

**Q. AIが「正解はBのはずだ」と言い出すことはありますか？**
A. AIには「登録された正解が絶対の基準で、変更してはいけない」と指示しています。
また、AIは採点結果にも理解度にも一切触れません。

**Q. AIがエラーになったら、回答は消えますか？**
A. 消えません。回答の記録と理解度の更新はAIを呼ぶ前に完了しています。
AI解説が失敗しても、画面にメッセージが出るだけです。

**Q. 「GEMINI_API_KEY がスクリプトプロパティに登録されていません」と出ます**
A. 手順2がまだです。プロパティ名の綴り（大文字・アンダースコア）も確認してください。

**Q. 「APIキーが正しくないか、権限がありません」と出ます**
A. コピー時に余分な空白が入っていないか確認し、必要なら手順1からキーを作り直してください。
